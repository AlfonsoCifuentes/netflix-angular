# Netflix Angular

> Clon Completo de Netflix con Angular y TypeScript

## Resumen

Una réplica completa y funcional de la interfaz de Netflix desarrollada con Angular y TypeScript. Este proyecto demuestra habilidades avanzadas de desarrollo frontend, incluyendo arquitectura de componentes complejos, diseño responsivo, y implementación de características interactivas similares a la plataforma original.

## Valor del proyecto

Demuestra capacidades avanzadas de desarrollo frontend para aplicaciones de streaming, experiencia en replicación de interfaces complejas, y habilidades en desarrollo de aplicaciones de entretenimiento digital.

Este repositorio resume una pieza de producto pensada para explicar el problema, la solucion aplicada y el criterio tecnico detras de la implementacion.

## Funcionalidades o puntos fuertes

- Interfaz idéntica a Netflix con diseño responsivo completo
- Arquitectura de componentes Angular escalable
- Sistema de navegación y categorización de contenido
- Carousel interactivo de películas y series
- Sistema de búsqueda y filtrado avanzado
- Gestión de estado con RxJS y observables
- Animaciones fluidas y transiciones CSS
